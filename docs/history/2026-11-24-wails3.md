# go-cine-sort 升级方案：Wails v2.17.1 → v3.1.0
## 0. 前提确认
- **Go 版本**：v3 要求 Go 1.26+，本项目已是 `go 1.27` ✅
- **好消息**：本项目分层良好，`internal/` 下除 `internal/app/bindings.go` 外全部业务代码（config/scanner/douban/imdb/organizer/store/netclient/service/youtube/logging/cache/media/model）**零依赖 Wails，完全不用改**，`go test ./...` 离线测试应保持绿色 ✅
- **改动集中区**：`main.go`、`app.go`、`internal/app/bindings.go`、`wails.json`、`build.ps1`、前端绑定层

## 2. Go 侧修改
### 2.1 `go.mod`
```text
require (
    github.com/wailsapp/wails/v3 v3.1.0   // 原 github.com/wailsapp/wails/v2 v2.17.1
)
```
执行 `go get github.com/wailsapp/wails/v3@v3.1.0 && go mod tidy`。注意：v2 的间接依赖（echo、gorilla/websocket、leaanthony 系列等）会被 tidy 掉，替换为 v3 自己的依赖树。
### 2.2 `main.go`（重写）
v2 的单入口 `wails.Run(&options.App{...})` 拆成 v3 的三段式：创建应用 → 创建窗口 → `app.Run()`。

```go
package main

import (
  "embed"
  "log"
  "github.com/wailsapp/wails/v3/pkg/application"
)

//go:embed all:../../frontend/dist
var assets embed.FS

func main() {
  a := NewApp()
  app := application.New(application.Options{
    Name: "Cine Sort",
    Services: []application.Service{
      application.NewService(a), // 原 Bind: []interface{}{a}
    },
    Assets: application.AssetOptions{ // 原 AssetServer: &assetserver.Options{Assets: assets}
      Handler: application.AssetFileServerFS(assets),
    },
    OnShutdown: nil, // 清理放 ServiceShutdown，见 2.3
  })
  a.app = app // 注入 app 引用，供事件/对话框使用
  win := app.Window.NewWithOptions(application.WebviewWindowOptions{
    Title: "Cine Sort · 电影整理工作台",
    Width: 1280, Height: 800, // 按现有 v2 options 平移
    MinWidth: 960, MinHeight: 640,
    // Windows/Mac 子选项按需平移
  })
  // 替代 v2 的 beforeClose：用户关窗时先取消运行中任务（不阻止关闭）
  win.OnWindowEvent(events.Common.WindowClosing, func(e *application.WindowEvent) {
    if a.svc != nil && a.svc.IsRunning() {
      _ = a.svc.CancelTask()
    }
  })
  if err := app.Run(); err != nil {
    log.Fatal(err)
  }
}
```
**v2 选项 → v3 映射表：**
| v2（options.App / runtime） | v3 |
| --- | --- |
| `wails.Run(&options.App{})` | `application.New(application.Options{})` + `app.Run()` |
| `Title/Width/Height/MinWidth/MinHeight` | `WebviewWindowOptions` 同名字段 |
| `AssetServer: &assetserver.Options{Assets}` | `Options.Assets: application.AssetOptions{Handler: application.AssetFileServerFS(assets)}` |
| `Bind: []interface{}{a}` | `Services: []application.Service{application.NewService(a)}` |
| `OnStartup` | `ServiceStartup(ctx, options)` 方法 |
| `OnDomReady` | 无直接等价；仅用于 debug 日志可删除，或监听 `events.Common.WindowRuntimeReady` |
| `OnBeforeClose` | 窗口 `OnWindowEvent(events.Common.WindowClosing, ...)` |
| `OnShutdown` | `ServiceShutdown()` 或 `Options.OnShutdown` |
| `wailsruntime.OpenDirectoryDialog(ctx, opts)` | `app.Dialog.OpenFile()...` 链式调用，见 2.3 |
### 2.3 `app.go`（Service 化改造）
```go
type App struct {
	app     *application.App   // 替代 ctx context.Context
	cfg     *config.AppConfig
	log     *logging.Logger
	svc     *service.Service
	initErr error
}
// 原 startup(ctx context.Context)：逻辑原样搬入，ctx 用参数
func (a *App) ServiceStartup(ctx context.Context, options application.ServiceOptions) error {
	// ...config.Load、logging.New、service.New 全部保持不变
	// appbridge.LogSink(ctx) → appbridge.LogSink(a.app)
	// appbridge.Events(ctx)   → appbridge.Events(a.app)
}
// 原 shutdown(ctx)：搬入
func (a *App) ServiceShutdown() {
	if a.svc != nil { _ = a.svc.Close() }
	if a.log != nil { _ = a.log.Close() }
}
// 删除：domReady、beforeClose（移到 main.go 的 WindowClosing 钩子）
// 删除：wailsruntime 导入
// 对话框替换
func (a *App) SelectDirectory(current string) (string, error) {
	path, err := a.app.Dialog.OpenFile().
		SetTitle("选择电影目录").
		SetDirectory(current).
		CanChooseDirectories(true).
		CanChooseFiles(false).
		PromptForSingleSelection()
	if err != nil {
		return "", err
	}
	if strings.TrimSpace(path) == "" {
		return current, nil // 取消时保持现有行为
	}
	return path, nil
}
```
**所有其余导出方法（`GetConfig`、`StartBatch`、`ProcessBySID`、`PlanYouTubeSort`、`ListHistory`、缓存系列、媒体标签系列……）签名与实现零改动**——v3 对注册 Service 的公开方法自动生成绑定。
### 2.4 `internal/app/bindings.go`
```go
import "github.com/wailsapp/wails/v3/pkg/application"
const (
	EventLog = "log"; EventProgress = "progress"       // 事件名字符串保持不变
	EventItem = "item-result"; EventTaskDone = "task-done"; EventTaskError = "task-error"
)
func Events(app *application.App) service.Events {
	return service.Events{
		Progress: func(p model.TaskProgress) { app.Event.Emit(EventProgress, p) },
		Item:     func(r model.ProcessResult) { app.Event.Emit(EventItem, r) },
		Done:     func(s model.TaskSummary)  { app.Event.Emit(EventTaskDone, s) },
		Error:    func(message string)       { app.Event.Emit(EventTaskError, TaskError{Message: message}) },
	}
}
func LogSink(app *application.App) func(logging.Entry) {
	return func(entry logging.Entry) { app.Event.Emit(EventLog, entry) }
}
```

### 3.2 `build/` 构建资产（一次性）
v3 构建系统从 Wails 内建改为 Taskfile 驱动，需要生成并入库一份构建资产：
```powershell
wails3 update build-assets -name "Cine Sort" -config build/config.yml -dir build
```
生成 `build/Taskfile.yml`、`build/config.yml`（应用名、图标路径、版本信息、Windows manifest 等）。`build/appicon.png` 与 `build/windows/icon.ico` 路径不变，现有文件直接沿用。
### 3.3 `build.ps1`
需要修改的点：
| 项 | v2 现状 | v3 改法 |
| --- | --- | --- |
| 版本常量 | `$WailsVersion = 'v2.17.1'`，`$VersionTag='2\.17\.1'` | `'v3.1.0'` / `'3\.1\.0'` |
| CLI 二进制名 | `wails` | `wails3`（`Resolve-WailsCli` 里 `Get-Command wails3`、GOPATH 下 `bin/wails3.exe`） |
| CLI 安装 | `go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.1` | `go install github.com/wailsapp/wails/v3/cmd/wails3@v3.1.0` |
| 构建命令 | `wails build -clean -s` | `wails3 build`（等价 `wails3 task build`；**`-clean -s` 标志删除**，精简产物由 Taskfile/`go build -ldflags "-w -s"` 控制） |
| 产物路径 | `build/bin/cine-sort.exe` | v3 默认 `bin/cine-sort.exe`——`$OutputExe` 改为该路径，或改 Taskfile 的 OUTPUT 变量映射回 `build/bin`（二选一，建议直接用 `bin/`） |
| `.gitignore` | — | 追加 `bin/` |
**注意**：`wails3 build` 的 stock Task 会按 wails.json 的 `frontend` 节自动执行 pnpm install/build，因此 build.ps1 里手写的 `pnpm.cmd install/run build` 段可以精简掉（保留工具链检查、图标存在性校验、产物校验即可）。
### 3.4 `generate-icon.ps1` / `tools/icongen` — 不改
纯 Go SVG→PNG/ICO 渲染，零 Wails 依赖；输出路径（`build/appicon.png`、`build/windows/icon.ico`、`frontend/public/logo.svg`）与 v3 期望一致。（可选：v3 也提供内置 `wails3 generate icons -input build/appicon.png`，但没有必要替换现有方案。）

### 4.3 `frontend/src/api/index.ts`（重写，隔离层保持对视图零影响）
v2 的 `window.go` 反射调用与 `window.runtime` 全局事件全部废弃：
```ts
import { Events } from '@wailsio/runtime'
import {
  Ping, GetConfig, SaveConfig, SelectDirectory, ScanDirectory,
  StartBatch, ProcessBySID, CancelTask, ListHistory, /* …全部方法 */
} from '@/bindings/go-cine-sort/app'   // 路径以生成结果为准
export const api = {
  ping: () => Ping(),
  getConfig: () => GetConfig(),
  // ……逐条映射，签名与 v2 完全一致，视图层无需变动
} 
type Unsubscribe = () => void
export function on<T>(name: string, handler: (p: T) => void): Unsubscribe {
  // v3：app.Event.Emit(name, payload) → 回调直接收到 payload
  return Events.On(name, (data: any) => handler(data as T)) as Unsubscribe
}
export const onLog = (h) => on<LogEntry>('log', h)          // 事件名不变
export const onProgress = (h) => on<TaskProgress>('progress', h)
// onItemResult / onTaskDone / onTaskError 同理
// off() 可保留 Events.Off(...names)，或统一改用 On 返回的退订函数
```
要点：
- 事件 payload：v3 稳定版文档明确 `Events.On('x', (data) => data.count)` 直接收 payload（与本项目 `Emit(name, 单个结构体)` 一一对应）。若升级后实测回调参数是事件对象，则在 `on()` 里统一解一层 `.data`，**只需改这一个适配函数**。
- 返回类型继续 cast 到 `@/types/index.ts` 的手写接口，`src/types/` 契约文件与四处同步规则**不变**（生成 bindings 里的 models 类不强制使用）。

## 6. v2 → v3 API 对照速查
| 类别 | v2 | v3 |
| --- | --- | --- |
| 应用启动 | `wails.Run(&options.App{})` | `application.New(Options)` → `app.Run()` |
| 服务注册 | `Bind: []interface{}{a}` | `application.NewService(a)` |
| 生命周期 | `startup/domReady/beforeClose/shutdown` | `ServiceStartup/ServiceShutdown` + WindowClosing 事件 + `OnShutdown` |
| 事件发射 | `runtime.EventsEmit(ctx, name, data)` | `app.Event.Emit(name, data)` |
| 目录选择 | `runtime.OpenDirectoryDialog(ctx, opts)` | `app.Dialog.OpenFile().CanChooseDirectories(true)...PromptForSingleSelection()` |
| 资源嵌入 | `assetserver.Options{Assets}` | `application.AssetFileServerFS(assets)` |
| 前端调用 | `window.go.main.App.X()` | 生成绑定直接 `import { X } from '@/bindings/...'` |
| 前端事件 | `window.runtime.EventsOn` | `@wailsio/runtime` 的 `Events.On`（返回退订函数） |
| CLI | `wails build -clean -s` / `wails dev` | `wails3 build` / `wails3 dev` / `wails3 generate bindings` |
| 构建系统 | Wails 内建 | Taskfile（`build/Taskfile.yml`） |

## 8. 风险与注意点
1. **早期事件可能丢失**：Go 在窗口 runtime 就绪前发出的 `log`/`progress` 事件前端收不到（v2 也有类似窗口期）。如日志面板开头缺失关键行，可在 ServiceStartup 缓冲、监听 `events.Common.WindowRuntimeReady` 后统一回放。
2. **`wails3 dev` 与 `pnpm -C frontend run dev`**：v3 推荐统一走 `wails3 dev`（代理到 devServerUrl）；单独跑 vite 的旧习惯需配合 `wails3 dev` 才有 Go 桥。
3. **产物路径变化**：`build/bin/` → `bin/`，凡引用旧路径的文档/脚本/CI 一并检查。
4. **不可回退式改动**：`main.go`/`app.go` 是重写不是微调，建议独立分支提交，v2 代码保留在 git 历史即可。
5. **版本钉死**：按官方建议在 go.mod 与 CI 中固定精确 `@v3.1.0`，不用 `@latest`（v3 系 nightly 频繁）。
